Iebūvētais IKEv2 VPN Windows

Kas nepieciešams

Windows dators ar internetu un atļauju instalēt TOLF iestatīšanas pakotni.

Darbību secība

  1. TOLF izvēlieties Windows → IKEv2 un izveidojiet vai izvēlieties ierīci.
  2. Lejupielādējiet šai ierīcei piedāvāto .ppkg pakotni. Ja iestatāt no tālruņa, pārsūtiet to uz vajadzīgo datoru.
  3. Atveriet .ppkg Windows un apstipriniet instalēšanu. Izmantojiet personīgo ierīces pakotni; sertifikāta autentifikācijai VPN lietotājvārds un parole nav vajadzīgi.
  4. Atveriet Iestatījumi → Tīkls un internets → VPN, izvēlieties TOLF savienojumu un pieslēdzieties.

Pārbaude un atvienošana

Pēc pieslēgšanās atveriet vietni. Lai atvienotos, izvēlieties to pašu savienojumu un nospiediet atvienošanas pogu.

Ja rodas problēma

Ja organizācijas politika aizliedz instalēšanu, sazinieties ar datora administratoru. Neinstalējiet citas personas pakotni savas vietā.
