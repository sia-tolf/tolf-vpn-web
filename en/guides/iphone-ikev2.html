Built-in IKEv2 VPN on iPhone and iPad

What you need

An iPhone or iPad with internet access and an installation link or TOLF account. No additional app is required.

Step by step

  1. If someone sent you an HTTPS installation link, open it in Safari on the target device. From a messenger, choose Open in Safari. Installing a ready-made profile does not require account sign-in.
  2. If you do not have a link, sign in to TOLF and choose iPhone / iPad → manual setup → built-in IKEv2 VPN. Select available settings and create a profile.
  3. Tap Install profile, then Allow when Safari asks to download the configuration profile.
  4. Open Settings → Profile Downloaded. If missing, open General → VPN & Device Management and select the downloaded TOLF profile.
  5. Tap Install, enter the device unlock passcode, confirm installation and tap Done. This is not your VPN password. The VPN password is already included in a ready-made TOLF profile.
  6. Open Settings → General → VPN & Device Management → VPN. Select the TOLF connection and switch it on.

Check and disconnect

Wait for Connected and check a website in Safari. Disconnect with the same VPN switch. If Connect On Demand is enabled, turn it off in the connection settings to prevent automatic connections.

If something goes wrong

The TOLF link lasts 24 hours from creation. After download, iOS allows 8 minutes to install the profile; download it again through the valid link if necessary. Ask for a new link if it has expired. Do not manually change server names or identifiers.
