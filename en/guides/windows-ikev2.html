Built-in IKEv2 VPN in Windows

What is Windows built-in VPN?

Windows includes a Microsoft VPN client with IKEv2/IPsec support. This TOLF method needs no separate VPN application: the setup package creates a system connection.

What the app lets you do

  • Encrypted IKEv2/IPsec connections using Windows.
  • Save the server and settings in a system VPN profile.
  • Connect and disconnect in Network & Internet → VPN.
  • Use the authentication settings and certificates specified by the TOLF profile.

When to choose it

Choose this method for a system VPN without a separate client. AnyConnect needs a different client. The setup package contains access settings, and IKEv2 availability depends on your network.

How to use it

Install your personal TOLF package once. Then open Windows VPN settings, select the TOLF connection and choose Connect. Select Disconnect on the same entry to stop it. If it fails, record the Windows error and test your regular internet connection without VPN.

Developer documentation

What you need

A Windows computer with internet access and permission to install the TOLF setup package.

Step by step

  1. In TOLF choose Windows → IKEv2 and create or select a device.
  2. Download the .ppkg package offered for this device. Transfer it to the target PC if setting up from a phone.
  3. Open the .ppkg in Windows and confirm installation. Use the personal device package; certificate authentication does not require a VPN username or password.
  4. Open Settings → Network & Internet → VPN, select the TOLF connection and choose Connect.

Check and disconnect

Open a website after connection. Select the same connection and choose Disconnect to stop it.

If something goes wrong

If organizational policy prevents installation, contact the computer administrator. Do not install another person’s package instead of yours.
