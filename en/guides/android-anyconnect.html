AnyConnect on Android

What you need

Cisco Secure Client (AnyConnect) from Google Play and TOLF access.

Step by step

  1. Install Cisco Secure Client. In TOLF choose Android → AnyConnect and confirm the client is installed.
  2. Create or select an access entry. Use the server address and settings shown for that entry.
  3. Add the connection in Cisco Secure Client. Import the client certificate supplied by TOLF; use an import password only if your account provides one.
  4. Select the certificate if requested and connect. Approve the Android VPN prompt.

Check and disconnect

Check status and website access. Disconnect in Cisco Secure Client.

If something goes wrong

Certificate formats and available actions depend on the client. Follow the selected access entry; do not substitute your website login for its certificate.
