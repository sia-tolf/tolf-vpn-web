TOLF with Shadowrocket on iPhone and iPad

What is Shadowrocket?

Shadowrocket is an independent networking app for iPhone and iPad, developed by Shadow Launch Technology Limited. It connects to servers and applies traffic rules. The app does not provide its own TOLF access or include VPN traffic.

What the app lets you do

  • Keep Moscow, Riga and New York in one TOLF configuration and select a server without importing a separate file for each.
  • Choose which sites use the tunnel and which use your regular connection. TOLF offers direct rules for Russian and Latvian domains.
  • Manage DNS settings, check connection logs and inspect how requests are routed.
  • Import a ready-made configuration instead of entering every server and rule manually.

When to choose it

Choose Shadowrocket if you want control over servers, DNS and individual site routes. For a simple connect/disconnect experience, Cisco Secure Client may be easier. Shadowrocket is paid separately; its purchase does not buy TOLF traffic.

How to use it

After import, select the TOLF configuration, use configuration-based routing to apply its rules, choose a server in the TOLF group and turn on the main connection switch. Disconnect with that switch. Available protocols and advanced functions depend on the app version; the TOLF file sets up AnyConnect/OpenConnect.

Get the app · Developer documentation

What you need

Shadowrocket for iOS is purchased separately from the App Store. You need a TOLF account and VPN access password.

Step by step

  1. In your account choose iPhone / iPad → manual setup → Shadowrocket. Install the app and confirm installation.
  2. Enter the requested access details. Optionally choose Russian and Latvian domains for direct access.
  3. Create TOLF_Shadowrocket.conf and send it to Shadowrocket using the supplied share menu or file import.
  4. Select the imported configuration and a server in the TOLF group in Shadowrocket. Enable the connection and allow iOS to add a VPN configuration.

Check and disconnect

Open a website. To apply direct-access rules, use configuration-based routing rather than forcing all traffic through the proxy. Disconnect with the main Shadowrocket switch.

If something goes wrong

The file contains access credentials. Share it only with an authorized recipient. Buying Shadowrocket does not include TOLF traffic.
