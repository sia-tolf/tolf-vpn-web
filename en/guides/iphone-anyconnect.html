AnyConnect on iPhone and iPad

What is Cisco Secure Client (AnyConnect)?

Cisco Secure Client is Cisco's application for secure remote network access. AnyConnect is the VPN component and familiar former client name. In TOLF, it connects your device to a compatible OpenConnect server; TOLF is not a Cisco-operated VPN service.

What the app lets you do

  • Create an encrypted connection using the TOLF access entry and personal client certificate.
  • Keep connection entries and connect or disconnect with a switch, without managing lists of site rules.
  • Supports TLS over TCP and DTLS over UDP. TOLF can use TCP when a UDP data channel cannot be established or maintained.
  • Supports reconnecting after interruptions and network changes, with connection status and diagnostic information.

When to choose it

Choose Cisco Secure Client for a straightforward AnyConnect connection. Shadowrocket on iPhone/iPad is an alternative when you want to edit site-routing rules. Reconnection time depends on the device, network and server; the app does not guarantee uninterrupted access in every network.

How to use it

Install the TOLF connection and certificate, select that connection in the app and enable VPN. Wait for the connected state and check a website. Disconnect using the same switch. On iPhone/iPad, Connect On Demand may be configured by the profile; Android does not use Apple's On Demand setting. The app and TOLF access are separate: installing the app alone does not grant service.

Get the app · Developer documentation

What you need

Cisco Secure Client (AnyConnect) from the App Store and TOLF AnyConnect access.

Step by step

  1. Install Cisco Secure Client and return to TOLF. Choose iPhone / iPad → manual setup → Cisco AnyConnect.
  2. Confirm the app is installed and create or select an access entry. If you received an installation link, open it on this device and follow its delivery page.
  3. Install the supplied profile through Settings → Profile Downloaded → Install. It includes the connection and client certificate.
  4. Open Cisco Secure Client, select the TOLF connection and enable VPN. Accept the system prompt if shown.

Check and disconnect

Check the connection status and open a website. Disconnect in Cisco Secure Client; check On Demand settings if it reconnects automatically.

If something goes wrong

Do not add another connection with an arbitrary server. If importing a certificate manually, follow the selected access entry in your account.
