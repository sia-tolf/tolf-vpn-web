IKEv2 with strongSwan on Android

What you need

strongSwan VPN Client from Google Play and a TOLF Android profile.

Step by step

  1. Install strongSwan VPN Client.
  2. Open the supplied profile link on Android, or sign in to TOLF and choose Android → IKEv2. Create a profile with the available settings you need.
  3. Tap Open in strongSwan, or download the .sswan file and open it in strongSwan. Confirm import.
  4. Select the imported connection and approve the Android VPN prompt.

Check and disconnect

Wait for connection and check a website. Disconnect in strongSwan. Always-on VPN is configured separately in Android settings.

If something goes wrong

If Android does not pass the file to the app, import the downloaded .sswan file from strongSwan. IKEv2 availability depends on your network.
