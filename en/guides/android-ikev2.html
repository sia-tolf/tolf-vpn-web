IKEv2 with strongSwan on Android

What is strongSwan VPN Client?

strongSwan VPN Client is the free, open-source Android app from the strongSwan project. It creates an encrypted IKEv2/IPsec tunnel to a VPN server. It is a connection tool, not a provider of ready-made servers or TOLF access.

What the app lets you do

  • Import a TOLF .sswan profile instead of manually entering server and authentication settings.
  • Save multiple VPN profiles and select the connection you need.
  • Supports password-based EAP and certificate authentication; use the method specified by your TOLF profile.
  • Provides connection status and logs for troubleshooting. Android can manage Always-on VPN separately.

When to choose it

Choose strongSwan for TOLF IKEv2 on Android. For TOLF AnyConnect use Cisco Secure Client instead. IKEv2 and AnyConnect are different protocols; if your network restricts IKEv2, installing strongSwan alone will not remove that restriction.

How to use it

Open the received profile in strongSwan, confirm import, select the saved entry and connect. Approve Android's VPN prompt on first use. Disconnect in the app. Always-on VPN and blocking connections without VPN are separate Android settings; enable them deliberately because they can prevent internet access while the VPN is down.

Get the app · Developer documentation

What you need

strongSwan VPN Client from Google Play and a TOLF Android profile.

Step by step

  1. Install strongSwan VPN Client.
  2. Open the supplied profile link on Android, or sign in to TOLF and choose Android → IKEv2. Create a profile with the available settings you need.
  3. Tap Open in strongSwan, or download the .sswan file and open it in strongSwan. Confirm import.
  4. Select the imported connection and approve the Android VPN prompt.

Check and disconnect

Wait for connection and check a website. Disconnect in strongSwan. Always-on VPN is configured separately in Android settings.

If something goes wrong

If Android does not pass the file to the app, import the downloaded .sswan file from strongSwan. IKEv2 availability depends on your network.
