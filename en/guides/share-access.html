How to send VPN setup to another person

What you need

An existing TOLF access entry and the recipient’s device. Shared access remains tied to the account that created it.

Step by step

  1. Create a separate access entry or profile for the target device and select a protocol.
  2. For IKEv2, copy the HTTPS installation link or show its QR code. Share .mobileconfig sends a profile file rather than an ordinary webpage.
  3. For AnyConnect, use Create installation link if available. Do not confuse it with Transfer to another device, which may require signing in to the same account.
  4. Send the link with the matching guide from this section. The recipient opens it on the target device and installs the profile or certificate.

Check and disconnect

Ask the recipient to check the connection and website access. Do not ask them to send passwords or private keys back.

If something goes wrong

Links are temporary; their expiry is shown at creation. IKEv2 links last 24 hours. Generate a new link if needed. Share credentials only with an authorized VPN user.
