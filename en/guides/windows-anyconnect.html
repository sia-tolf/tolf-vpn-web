AnyConnect with OpenConnect GUI in Windows

What is OpenConnect GUI?

OpenConnect GUI is a free, open-source graphical VPN client for Windows. It uses OpenConnect to connect to compatible AnyConnect VPN servers, including TOLF. It is an independent project, not a Cisco application.

What the app lets you do

  • Save connection profiles instead of entering settings every time.
  • Connect to TOLF using your personal client certificate and private key.
  • Encrypt traffic; OpenConnect supports TLS over TCP and DTLS over UDP.
  • View connection status and logs to investigate errors.

When to choose it

Choose it for the AnyConnect method offered by TOLF on Windows. Windows built-in IKEv2 uses a different protocol and is configured separately. Installing OpenConnect GUI alone does not create TOLF access.

How to use it

Create a profile once using the settings from your TOLF account and select the certificate and key files. Then select the saved profile and choose Connect; use Disconnect to stop it. Keep the access files on your computer: the client needs the private key, which is not intended for publication.

Developer documentation

What you need

OpenConnect GUI for Windows and personal TOLF AnyConnect access.

Step by step

  1. In TOLF choose Windows → AnyConnect. Install the client linked by setup.
  2. Create or select an access entry. Download the supplied certificate and key files and save them on your computer.
  3. Create a connection profile in OpenConnect GUI. Enter the server, client certificate and key from the selected access entry. Use the file formats shown in your account; a .p12 file does not replace the certificate and key fields.
  4. Save the profile and connect. Do not disable server certificate verification if a trust error occurs.

Check and disconnect

Wait for connection and check websites. Use Disconnect in OpenConnect GUI to stop it.

If something goes wrong

Field names depend on client version. If your account offers a setup installer, follow its instructions. Do not share the private key with unrelated people.
