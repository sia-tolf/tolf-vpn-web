AnyConnect with OpenConnect GUI in Windows

What you need

OpenConnect GUI for Windows and personal TOLF AnyConnect access.

Step by step

  1. In TOLF choose Windows → AnyConnect. Install the client linked by setup.
  2. Create or select an access entry. Download the supplied certificate and key files and save them on your computer.
  3. Create a connection profile in OpenConnect GUI. Enter the server, client certificate and key from the selected access entry. Use the file formats shown in your account; a .p12 file does not replace the certificate and key fields.
  4. Save the profile and connect. Do not disable server certificate verification if a trust error occurs.

Check and disconnect

Wait for connection and check websites. Use Disconnect in OpenConnect GUI to stop it.

If something goes wrong

Field names depend on client version. If your account offers a setup installer, follow its instructions. Do not share the private key with unrelated people.
