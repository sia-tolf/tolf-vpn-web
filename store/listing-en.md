# TOLF VPN

Draft listing — review after packaged-build testing, before submission.

## Short description

Set up and manage your TOLF VPN connections using Windows IKEv2.

## Description

TOLF VPN helps you configure and control VPN access on your Windows computer.
Use your personal setup link from vpn.tolf.is to add a connection, then connect
or disconnect from the application, compact widget or system-tray icon.

Each profile shows its computer name, VPN entry point and routing mode.
You can specify IPv4 addresses and networks that should remain outside the VPN
and save an updated VPN password in Windows.

Connections use the built-in Windows IKEv2 client. The Windows application
controls the connection; the VPN tunnel is maintained by Windows.

A TOLF account and a Windows device setup link are required. Create and manage
your devices, entry points and routing modes at vpn.tolf.is. Riga and Moscow are
VPN entry points; available routing modes depend on the selected entry point.

For remote computers, configure the required network exclusions before
connecting. An exclusion for an RDP peer does not cover every remote-access
network configuration.

## Features

- Set up Windows IKEv2 VPN connections from a personal TOLF setup link.
- Connect and disconnect through a desktop window, widget or tray icon.
- Distinguish profiles by computer name, location and routing mode.
- Configure IPv4 destinations outside the tunnel.
- Update locally saved VPN credentials.
