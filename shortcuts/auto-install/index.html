Обновить команду TOLF

Для подключения «TOLF Москва iPhone».

Включение: On Demand → On, затем Cisco Start.
Выключение: On Demand → Off, затем отключение выбранного VPN.

Скачать обновлённую TOLF

Откройте файл из загрузок Safari и добавьте команду «TOLF Москва iPhone». Сохраните её название. Затем заново установите профиль с сайта с отмеченной установкой значка: вместо ON/OFF появится один значок «TOLF Москва» с меню.

После включения или выключения VPN команда возвращает на домашний экран. Текстовый результат не передаётся. Управление VPN и On Demand сохранено.
