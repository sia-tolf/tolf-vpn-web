Which server should I choose?

In Russia: start with Moscow. Your device connects to a Russian entry server; traffic that needs Riga travels over the link between our servers. Your device does not need a direct VPN connection to a foreign server. Moscow requires an activated promo code.

Outside Russia: start with Riga, or another available server outside Russia. Your device can reach the foreign entry server directly, while Russian destinations can use the Moscow exit.

This recommendation follows our network layout. Connection quality depends on your provider and location; it does not guarantee a faster connection or availability on every network.

The entry server and the exit IP are different things. With the default settings, Russian destinations in the server’s lists use Moscow; other Internet traffic uses Riga. This works with either entry server. Leave Local ID empty in the website: Riga uses sr, and Moscow uses its empty default value.

Why TOLF VPN?

  • Built into Apple devices. Install a configuration profile and use the system IKEv2 VPN, without a separate VPN app.
  • One connection, two exits. The default routing can use Russian IP addresses for Russian destinations and Riga for other traffic, without manually switching VPNs for each site.
  • Sign in with a Passkey. There is no account password to invent or remember.
  • Ready-to-install profiles. The website manages VPN access, generates profiles and lets experienced users choose Local ID.

Glossary

VPN
An encrypted connection between your device and a VPN server. Traffic routed through it reaches the Internet through the configured exit.
Account
Your TOLF identity: it links your Passkeys, recovery code and server permissions.
VPN access
Your server-side VPN credentials. Creating an account alone does not connect your device: create VPN access, install a profile and turn the VPN on.
Passkey
A digital key for signing in to the website, stored by your device or password manager. You approve its use with Face ID, Touch ID, a device passcode or your manager. It is separate from the VPN password.
Username
The automatically assigned VPN login, often starting with user_. It identifies your VPN connection; it is not your website sign-in method.
VPN password
The secret used with your VPN username. TOLF puts it in the profile automatically. Riga and Moscow share this password for your VPN access.
Device passcode
The code used to unlock your iPhone or iPad. A system request for this code during installation is separate from your VPN password.
Recovery / Recovery Code
Account recovery and its secret code. The code lets you register a new Passkey if you lose access to your existing ones. Save it securely; it is not a promo code.
Promo code
A six-character invitation code that unlocks Moscow for your account alongside Riga. It does not sign you in or replace your VPN password.
Profile / Mobile Config
A .mobileconfig file containing the server, routing identifier and VPN credentials for installation on an Apple device.
Install link
A temporary link to the profile page and download. It lasts 24 hours. Treat the link and downloaded profile as private: the profile contains VPN credentials.
Server / Remote ID
Server is the address your device connects to. Remote ID identifies the expected VPN server and is checked against its certificate. Both are filled in automatically.
Local ID
A connection identifier. In TOLF it selects a server routing mode. It is not your username, location or promo code.
Routing / exit IP
Routing chooses where traffic travels. The exit IP is the public address a destination sees for traffic leaving that route.
On Demand
A system option for automatic VPN connection according to profile rules. TOLF profiles expose this option with it off by default; its presence alone does not mean the VPN is always connected.
MOBIKE
A mechanism that can help an IKEv2 connection adapt when the device’s network address changes, for example when moving between Wi-Fi and mobile data.
DPD — Dead Peer Detection
A check that helps detect when the other end of the VPN connection is no longer responding.

Frequently Asked Questions

How do I get started?

Create an account with a Passkey and save the Recovery Code. Sign in, choose a server and create VPN access. Generate an install link, open “Install on Apple Device”, download the Mobile Config and finish installation in device settings. Then select the installed VPN and connect.

Does “Active” mean my device is connected?

No. It means VPN access exists on the server. Check the connection state in your device’s VPN settings. You can close the website after connecting; signing out of the website does not turn the VPN off.

Does selecting Moscow or Riga on the website switch my VPN?

No. It chooses which profile to generate. To change the actual connection, install the appropriate profile and select it in your device’s VPN settings.

Which Local ID values are available?

Riga: sr is the default split routing; ru sends Internet traffic through Moscow.

Moscow: an empty value is the default split routing; ru uses Moscow for Internet traffic, and lv uses Riga. Moscow’s explicit sr is a different mode: DNS and destinations in the configured Riga lists use Riga; other Internet traffic uses Moscow.

After changing Local ID, generate and install a new profile. Use the website’s hint for the selected server.

Why do different sites see different countries?

That is expected with default split routing. Russian destinations are identified using the server’s IP and domain lists, including .ru, .su and .рф. A site’s supporting domains, DNS settings and IP-location databases can affect the result; a domain suffix alone is not a guarantee.

What expires after 24 hours?

The install link expires, not your account or an already installed VPN profile. Sign in and generate another link when needed.

What should I do if I lose my Passkey?

Use another Passkey for the same account, or choose “Recover account” and enter your Recovery Code. Complete creation of a new Passkey, save the newly issued Recovery Code and sign in. The previous recovery code stops working. Without a usable Passkey, recovery code or existing signed-in session, the website cannot restore access.

What happens when I change the VPN password?

The password changes for both Riga and Moscow. Generate and install a new profile for every server and device you use. Old profiles cannot reconnect with the old password. Your Passkeys and Recovery Code are unchanged.

What is the difference between deleting VPN access and deleting my account?

Deleting VPN access removes VPN credentials on both servers, while preserving your account, Passkeys and promo entitlement. You can create VPN access again.

Deleting the account also removes its Passkey registrations, sessions, Recovery Code and server permissions. It cannot be undone. Removing a profile only from your device does not delete the account.

Do I need a separate account for another device?

No. Sign in to the same account using a Passkey available on that device, then obtain and install a profile. Passkey availability across devices depends on your password manager and its sync settings.

Выбор сервера Преимущества Глоссарий Вопросы и ответы

Какой сервер выбрать?

В России рекомендуем начать с Москвы. Устройство подключается к российскому серверу, а трафик, которому нужна Рига, передаётся по соединению между нашими серверами. Устройству не требуется прямое VPN-соединение с зарубежным сервером. Для Москвы нужен активированный промокод.

За пределами России рекомендуем начать с Риги или другого доступного сервера вне России. Устройство подключается напрямую к зарубежной точке входа, а российские направления могут использовать выход через Москву.

Рекомендация основана на устройстве нашей сети. Качество связи зависит от оператора и вашего местоположения: это не гарантия более высокой скорости или работы в любой сети.

Сервер подключения и выходной IP — разные вещи. По умолчанию российские направления из списков сервера выходят через Москву, остальной интернет-трафик — через Ригу. Это работает при подключении к любому из двух серверов. Оставьте Local ID на сайте пустым: для Риги будет использован sr, для Москвы — пустое значение по умолчанию.

Преимущества TOLF VPN

  • Системный VPN на устройствах Apple. Установите профиль и используйте встроенный IKEv2 без отдельного VPN-приложения.
  • Одно подключение — два выхода. Маршрутизация по умолчанию позволяет открывать российские направления с российского IP, остальные — через Ригу, без ручного переключения VPN для каждого сайта.
  • Вход с Passkey. Не нужно придумывать и запоминать пароль от аккаунта.
  • Готовые профили. В кабинете можно управлять VPN-доступом, создавать профили и выбирать Local ID, если нужна другая маршрутизация.

Глоссарий

VPN
Зашифрованное соединение устройства с VPN-сервером. Направленный в него трафик выходит в интернет через настроенную точку выхода.
Аккаунт
Ваша учётная запись TOLF. Она объединяет Passkey, код восстановления и права доступа к серверам.
VPN-доступ
Ваши VPN-учётные данные на серверах. Одного аккаунта недостаточно для подключения: нужно создать VPN-доступ, установить профиль и включить VPN.
Passkey — ключ входа
Цифровой ключ для входа на сайт, который хранится на устройстве или в менеджере паролей. Использование подтверждается через Face ID, Touch ID, код устройства или менеджер. Это отдельный ключ, а не пароль VPN.
Username — имя пользователя
Автоматически назначенный VPN-логин, обычно начинающийся с user_. Он используется при VPN-подключении; для входа в кабинет используется Passkey.
Пароль VPN
Секрет для подключения вместе с VPN-логином. TOLF автоматически записывает его в профиль. Для вашего VPN-доступа Рига и Москва используют общий пароль.
Код устройства
Код разблокировки iPhone или iPad. Если система запрашивает его при установке профиля, это отдельный код, не пароль VPN.
Recovery / Recovery Code
Восстановление аккаунта и секретный код для него. Позволяет создать новый Passkey при потере доступа к прежним. Сохраните код в надёжном месте; это не промокод.
Промокод
Пригласительный код из шести символов. Открывает вашему аккаунту Москву дополнительно к Риге. Не заменяет Passkey или пароль VPN.
Профиль / Mobile Config
Файл .mobileconfig с адресом сервера, идентификатором маршрутизации и VPN-учётными данными для установки на устройство Apple.
Ссылка для установки
Временная ссылка на страницу параметров и загрузку профиля. Действует 24 часа. Ссылку и скачанный профиль храните конфиденциально: профиль содержит VPN-учётные данные.
Server / Remote ID
Server — адрес подключения. Remote ID — ожидаемый идентификатор VPN-сервера, который проверяется по его сертификату. Оба значения заполняются автоматически.
Local ID
Идентификатор подключения. В TOLF он выбирает режим маршрутизации на сервере. Это не ваш логин, местоположение или промокод.
Маршрутизация / выходной IP
Маршрутизация определяет путь трафика. Выходной IP — публичный адрес, который видит сайт для трафика, пришедшего по этому пути.
On Demand
Системная возможность автоматического подключения VPN по правилам профиля. В профилях TOLF опция доступна и по умолчанию выключена; наличие переключателя само по себе не означает постоянного подключения.
MOBIKE
Механизм, помогающий IKEv2-соединению приспособиться к смене сетевого адреса устройства, например при переходе между Wi-Fi и мобильной сетью.
DPD — Dead Peer Detection
Проверка, помогающая обнаружить, что другая сторона VPN-соединения перестала отвечать.

Частые вопросы — FAQ

С чего начать?

Создайте аккаунт с Passkey и сохраните Recovery Code. Войдите, выберите сервер и создайте VPN-доступ. Создайте ссылку для установки, нажмите «Установить на устройство Apple», скачайте Mobile Config и завершите установку в настройках устройства. Затем выберите установленный VPN и подключитесь.

Статус «Активен» означает, что устройство подключено?

Нет. Это означает, что на сервере создан VPN-доступ. Состояние соединения проверяйте в настройках VPN устройства. После подключения сайт можно закрыть; выход из кабинета не отключает VPN.

Выбор Москвы или Риги на сайте переключает VPN?

Нет. Так вы выбираете, для какого сервера создать профиль. Для смены действующего подключения установите нужный профиль и выберите его в настройках VPN устройства.

Какие значения Local ID доступны?

Рига: sr — разделённая маршрутизация по умолчанию; ru — интернет-трафик через Москву.

Москва: пустое поле — разделённая маршрутизация по умолчанию; ru — интернет-трафик через Москву; lv — через Ригу. Явно введённое sr на Москве выбирает другой режим: DNS и направления из заданных списков для Риги идут через Ригу, остальной интернет-трафик — через Москву.

После изменения Local ID создайте и установите новый профиль. Ориентируйтесь на подсказку для выбранного сервера в кабинете.

Почему разные сайты показывают разные страны?

При разделённой маршрутизации это ожидаемо. Российские направления определяются по IP- и доменным спискам сервера, включая .ru, .su и .рф. На результат могут влиять дополнительные домены сайта, настройки DNS и базы определения страны по IP; одного окончания домена недостаточно для гарантии.

Что перестаёт действовать через 24 часа?

Ссылка для установки, а не аккаунт или уже установленный VPN-профиль. Если нужна новая ссылка, создайте её в кабинете.

Что делать, если потерян Passkey?

Войдите с другим Passkey того же аккаунта либо нажмите «Восстановить аккаунт» и введите Recovery Code. Завершите создание нового Passkey, сохраните новый Recovery Code и войдите. Прежний код восстановления перестанет действовать. Если нет доступного Passkey, кода восстановления или уже открытой сессии кабинета, восстановить доступ через сайт не получится.

Что происходит при смене пароля VPN?

Пароль меняется для Риги и Москвы. Создайте и установите новые профили для всех используемых серверов и устройств. Старые профили не смогут переподключиться с прежним паролем. Passkey и Recovery Code при этом не меняются.

Чем удаление VPN-доступа отличается от удаления аккаунта?

Удаление VPN-доступа убирает VPN-учётные данные на обоих серверах. Аккаунт, Passkey и право, открытое промокодом, сохраняются. VPN-доступ можно создать заново.

Удаление аккаунта также удаляет регистрации Passkey, сессии, Recovery Code и права на серверы. Отменить его нельзя. Удаление профиля только с устройства не удаляет аккаунт.

Для другого устройства нужен новый аккаунт?

Нет. Войдите в тот же аккаунт с доступным на этом устройстве Passkey, получите профиль и установите его. Доступность Passkey на разных устройствах зависит от менеджера паролей и его настроек синхронизации.
