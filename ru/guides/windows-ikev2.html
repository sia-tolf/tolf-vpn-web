Встроенный IKEv2 VPN в Windows

Что такое встроенный VPN Windows?

Windows уже содержит VPN-клиент Microsoft с поддержкой IKEv2/IPsec. Для этого способа TOLF отдельное приложение устанавливать не нужно: пакет настройки создаёт подключение в системе.

Что позволяет приложение

  • Шифрованное подключение IKEv2/IPsec средствами Windows.
  • Сохранение сервера и параметров в системном VPN-профиле.
  • Подключение и отключение в разделе «Сеть и Интернет» → «VPN».
  • Использование параметров авторизации и сертификатов, заданных профилем TOLF.

Когда его выбрать

Выбирайте этот способ, если хотите пользоваться системным VPN без отдельного клиента. Для AnyConnect нужен другой клиент. Пакет настройки содержит параметры доступа, а доступность IKEv2 зависит от сети.

Как им пользоваться

Установите персональный пакет TOLF один раз. Затем откройте параметры VPN Windows, выберите подключение TOLF и нажмите «Подключиться». Для завершения работы нажмите «Отключиться» у того же подключения. При проблеме запишите текст ошибки Windows и проверьте обычный интернет без VPN.

Описание разработчика

Что понадобится

Компьютер Windows, интернет и права на установку пакета настройки TOLF.

Порядок действий

  1. В TOLF выберите Windows → IKEv2 и создайте или выберите устройство.
  2. Скачайте пакет .ppkg, предложенный для этого устройства. Передайте его на нужный компьютер, если настраиваете с телефона.
  3. Откройте .ppkg в Windows и подтвердите установку. Используйте персональный пакет устройства; при сертификатной авторизации логин и пароль VPN не требуются.
  4. Откройте «Параметры» → «Сеть и Интернет» → «VPN», выберите созданное подключение TOLF и нажмите «Подключиться».

Проверка и отключение

После подключения откройте сайт. Для отключения выберите то же подключение и нажмите «Отключиться».

Если возникла проблема

Если установка запрещена политикой организации, обратитесь к администратору компьютера. Не устанавливайте чужой пакет вместо своего.
