AnyConnect через OpenConnect GUI в Windows

Что такое OpenConnect GUI?

OpenConnect GUI — бесплатный клиент с открытым исходным кодом и графическим интерфейсом для Windows. Он использует OpenConnect для подключения к совместимым VPN-серверам AnyConnect, включая TOLF. Это самостоятельный проект, не приложение компании Cisco.

Что позволяет приложение

  • Сохранение профилей подключения, чтобы не вводить параметры при каждом запуске.
  • Подключение к TOLF с персональным клиентским сертификатом и закрытым ключом.
  • Шифрованная передача данных; OpenConnect поддерживает TLS через TCP и DTLS через UDP.
  • Просмотр состояния подключения и журнала для разбора ошибок.

Когда его выбрать

Выбирайте его для способа AnyConnect, предложенного TOLF в Windows. Встроенное подключение Windows IKEv2 использует другой протокол и настраивается отдельно. Установка OpenConnect GUI сама по себе не создаёт доступ TOLF.

Как им пользоваться

Один раз создайте профиль по параметрам из кабинета TOLF, укажите сертификат и ключ. Затем выбирайте сохранённый профиль и нажимайте Connect; для отключения — Disconnect. Храните файлы доступа на компьютере: закрытый ключ нужен клиенту и не предназначен для публикации.

Описание разработчика

Что понадобится

OpenConnect GUI для Windows и персональный доступ AnyConnect TOLF.

Порядок действий

  1. В TOLF выберите Windows → AnyConnect. Установите клиент по ссылке, предложенной в настройке.
  2. Создайте или выберите доступ. Скачайте предложенные файлы сертификата и ключа и сохраните их на своём компьютере.
  3. В OpenConnect GUI создайте профиль соединения. Укажите сервер, клиентский сертификат и ключ из выбранного доступа. Для файлов используйте форматы, указанные в кабинете; .p12 не заменяет поля сертификата и ключа.
  4. Сохраните профиль и подключитесь. Не отключайте проверку серверного сертификата при ошибке доверия.

Проверка и отключение

Дождитесь подключения и проверьте сайты. Отключитесь кнопкой Disconnect в OpenConnect GUI.

Если возникла проблема

Названия полей зависят от версии клиента. Если кабинет предлагает готовый установщик, используйте его инструкции. Не отправляйте закрытый ключ посторонним.
