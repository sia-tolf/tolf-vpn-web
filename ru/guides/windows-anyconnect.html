AnyConnect через OpenConnect GUI в Windows

Что понадобится

OpenConnect GUI для Windows и персональный доступ AnyConnect TOLF.

Порядок действий

  1. В TOLF выберите Windows → AnyConnect. Установите клиент по ссылке, предложенной в настройке.
  2. Создайте или выберите доступ. Скачайте предложенные файлы сертификата и ключа и сохраните их на своём компьютере.
  3. В OpenConnect GUI создайте профиль соединения. Укажите сервер, клиентский сертификат и ключ из выбранного доступа. Для файлов используйте форматы, указанные в кабинете; .p12 не заменяет поля сертификата и ключа.
  4. Сохраните профиль и подключитесь. Не отключайте проверку серверного сертификата при ошибке доверия.

Проверка и отключение

Дождитесь подключения и проверьте сайты. Отключитесь кнопкой Disconnect в OpenConnect GUI.

Если возникла проблема

Названия полей зависят от версии клиента. Если кабинет предлагает готовый установщик, используйте его инструкции. Не отправляйте закрытый ключ посторонним.
